# odoo-original

Odoo 19 Community tal cual sale del repositorio oficial (`github.com/odoo/odoo`, rama `19.0`),
construido desde el código fuente en el `Dockerfile` de este repo, con PostgreSQL 16. Base sola,
sin apps ni datos de demo. Sirve como referencia de comparación: al arrancar, el contenedor
imprime el commit exacto de `odoo/odoo` con el que se construyó.
